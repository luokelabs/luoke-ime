# 评测：准确率和速度

对外引用的数字（官网、介绍）都以这一页为准。每个数字都写明测的是什么、怎么测、在什么芯片上测的；更细的表和别的组合见[小鹤引擎](../engines/xiaohe/README.md)和[全拼引擎](../engines/quanpin/README.md)。实现改了要回来重测、更新这里。

## 评测集

- **博客语料 600 句**：作者自己写的博客文字，按句子回放按键（小鹤双拼的键；全拼把同样的句子换成全拼的键）。前文是同一篇里这一句前面的文字。
- 语料是作者的私人文字，**不公开**。仓库里只有评测程序（`engines/xiaohe/bench.py`、`engines/personal/eval_predict.py`），发布用的证据只记结论、评测集的哈希和逐条对错，不带原文（`scripts/evidence.py`）。用自己的语料可以复现同样的测法。

## 怎么测

- **首选准确率**：首选和要打的那一句完全一样的比例（整句对才算对）。
- **逐键打字**（`bench.py --typing 120`）：像人打字一样每 120 ms 按一个键，引擎照壳的用法边打边答。最后一个键之后再按空格，算上屏的是哪一份候选：模型还在算时，壳最多再等 150 ms，等不到就上屏苹果和 RIME 先给的那份。
  - **按空格前停顿 0 / 100 / 200 ms**：打完最后一个键立刻按空格、停 0.1 秒、停 0.2 秒再按。平常打字按空格前的间隔大约就有 0.1 秒。
  - **到选好**：最后一个键到模型选好的那份候选到达的时间，中位数（p50）和九成（p90）。
  - **第一份答复**：最后一个键到候选窗里出现候选（苹果和 RIME 先给的那份）的时间。
- **经螺壳测**（`--scorer hub`）：打分走螺壳（luoke-core）的 `luoke-ime.rerank` 任务，和用户装好以后一样，模型是 Qwen3.5-0.8B-Base 4bit。
- **完整 / 小档**：螺壳装好时用固定的测试请求量一次这台机器打分多快，比 50 ms 慢的机器给重排标 `slow`，输入法就用小档：每一步少给模型一半候选，一次重排最多 2 步（详见[小鹤引擎的「慢的机器」](../engines/xiaohe/README.md)）。按实测分，不按内存。实测打分：M5 Max 约 14–18 ms（完整），基础款 M4 约 59 ms、M1 约 135 ms（小档）。

## 结果

### 首选准确率（引擎总来得及时）

| | 首选准确率 |
|---|---|
| 苹果自带的双拼 | 78.8% |
| 螺壳，只用苹果和 RIME 的候选（没有模型时） | 78.8% |
| **螺壳，本机模型按前文重排（完整）** | **89.8%**（小鹤、全拼一样；macOS 26 上小鹤 90.0%） |
| 螺壳，小档 | 88.8% |

`bench.py --typing 0`：逐键打，每个键都等引擎答完，结果是确定的。M5 Max、macOS 27。全拼和小鹤 600 句里只有 1 句不同。

### 逐键打字时按空格上屏的首选

| 芯片（档） | 到选好 p50 / p90 | 第一份答复 p90 | 停顿 0 / 100 / 200 ms 时上屏的首选 |
|---|---|---|---|
| M5 Max（完整） | 42 / 70 ms | — | 选好的 p90 在壳等的 150 ms 以内，按空格时几乎总能用上模型那份 |
| M1 16 GB（小档） | 150 / 183 ms | 32 ms | 83.5% / 88.0% / 88.2% |

- M5 Max：经个人化组件打分，`bench.py --typing 120`，现在的引擎（逐词重排时边打边定词、沿用已定的词）。更早的版本是 57 / 76 ms（模型搬进个人化组件后 60 / 77 ms），那时停顿 100 ms 和不停顿上屏的首选都是 90.5%；现在这一版没有单独列按空格时的上屏首选，引擎总来得及时是 89.8%（上表）。
- M1：经螺壳实测，16 GB 测试机，小档（最多 2 步、先答新键）。
- 基础款 M4 是小档，没有单独测这一组；按打分速度在 M5 Max 和 M1 之间。
- 螺壳没装或不可用时：候选就是苹果和 RIME 的，首选 78.8%，没有重排和联想。

### 联想

`eval_predict.py`，同一份博客语料，只测模型那一路（不含用户自己写过的说法），M5 Max：

- 模型对下一个词的把握 ≥ 0.2 才给，约 **7%** 的上屏会出联想；
- 出联想时，第一个就对的 **41%**，前三个里有对的 49%；
- 每次 18–24 ms。

## 复现

```bash
cd engines/xiaohe && ./build.sh
./bench.py 语料.tsv --typing 0                       # 首选准确率（结果是确定的）
./bench.py 语料.tsv --typing 120                     # 逐键打字，按空格时上屏的是哪一份
./bench.py 语料.tsv --typing 0 --scorer hub --hub <socket> --result 证据.json   # 经螺壳测，写一份证据
python3 ../personal/eval_predict.py 语料.tsv --hub <socket>   # 联想，经螺壳续写
```

语料是一行一句的 TSV：类别、前文（`-` 表示没有，`⏎` 表示换行）、按键、正确结果，`#` 开头的行跳过；详见 `bench.py` 开头的说明。
