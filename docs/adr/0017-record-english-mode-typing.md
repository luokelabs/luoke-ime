# 英文模式下敲的字也记进记忆，只给记忆取英文专名

2026-11-09 定。语音的热词从记忆里的常用说法（`term`）来，转写最容易错的人名和英文专名（Claude Code 听成 Cloud Code、GitHub 听成 Jetpack）给了热词就对；可英文专名多半是在英文模式下敲的，英文模式下按键直接交给应用、不经输入法上屏，记忆里没有这些字。luoke-mem 要这些字，只从里面取英文专名。

做法：英文模式下，壳在放行按键时顺手攒一段：字母、数字、符号和空格接上去，退格去掉最后一个字；回车、挪光标、点鼠标、组合键、切走、切回中文时收尾，至少两个字、里面有字母的，作为一次上屏转给个人化组件，`kind` 是 `english`（引擎协议「个人化组件」）。组件把它单独记一条（不和前后输入法上屏的合成一段），`data.kind` 标着 `english`；联想不用它。一段最长 200 字。

- **和中文的规矩一样**：安全输入（密码框）、设了禁止记录的应用、暂停记录时都不攒；凭证由组件照中文一样遮掉，健康、法律、宗教政治照样标类别。
- **终端里不攒**：命令行里输密码的提示（`sudo`、`ssh`）不一定开安全输入，按键攒下来就是明文密码。终端里打的命令、路径对专名也没多大用。按 `ShellConfig.terminals` 的名单（和「终端里默认不联想」同一份）。
- **按按键攒，不读回应用里的字**：读光标前的字准，但英文模式下每个键都去读，有的应用慢；按键攒的在用户挪了光标、用了自动补全时会和屏幕上的不一样，所以一挪光标就收尾，不跨过去拼。记忆要连着 3 天都出现才认作常用说法，偶尔一段对不上的不会进热词。

## Considered Options

- **不记英文模式**：英文专名只能从中文模式里大写开头打的、语音说的和邮件里来，来得慢、少。
- **语音设置里让用户自己填常用词**：定了从记忆里拿，不另设词表。
- **终端里也记，只遮像密码的串**：口令不一定像凭证（`hunter2`），遮不住。
