# 壳在本机记使用计数：只有次数，不看记忆记录开没开

2026-11-04 定。离线评测（博客语料、用户自己上屏按时间切开的那段）只能看「给出的候选、联想会不会对」，看不到用户真用的时候选没选、是不是被打扰。联想的新排法（0.1.50）就是靠离线数字定的，合进去以后需要真用时的数字来对照。

做法：壳记一份按天合计的**使用计数**（`Usage`，`~/.luoke/ime/usage.json`）：打字引擎的上屏次数、选的候选里首选和别的各几段、上屏后紧接着按退格的次数、联想亮出／打开／选中的次数和选中的字数。不记内容、不记应用，不上传，留 90 天；设置窗口「高级」里显示最近 7 天、能清零。

- **密码框里、暂停所有记录、禁止记录的应用里不记**：用户在这些地方要的是什么都不留下，次数也算留下的东西。
- **和记忆记录开没开无关**：记忆记录管的是打了什么，计数里没有内容，也不进记忆；关掉记忆记录的人照样能看自己的统计。

## Considered Options

- **从记忆里算**：记忆里只有上屏的字，没有联想亮出了几次、按没按 Tab、选的是第几个候选，算不出来。
- **按应用分开记**：能看出终端这类应用里联想没用，但应用名本身是用户在哪儿打字的记录，先不记；要用时再定。
- **跟着记忆记录的开关**：关了记忆的人就看不到自己的统计；计数里没有内容，没有理由跟着关。
