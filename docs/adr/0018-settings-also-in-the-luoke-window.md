# 设置在螺壳主窗口里也放一份，和自己的设置窗口并存

2026-11-09 定。螺壳主窗口把邮件助手、记忆都画成侧栏里的应用页，问输入法要不要也画进去。输入法和别的应用不一样：它是单独的 app，没装螺壳也能用，麦克风权限也是它自己向系统要的。

定下的：

- **只多一份**：主窗口侧栏的「螺壳输入法」应用页里能改设置，输入法自己的设置窗口、菜单里的「设置…」都保留，两边改的是同一份 `~/.luoke/ime/settings.json`。
- **权限照旧**：麦克风仍由输入法自己要，配件清单里不写 `permissions`，不进螺壳的权限页。
- **怎么接**：照 luoke-agent 工具协议 §2a（`transport: "stdio"`）。螺壳本体按请求起包里的 `Contents/MacOS/luoke-ime mcp`，它读一条请求、答一行就退出，不常驻、不开 socket；输入法没在跑时设置页也能看、能改。页面是 A2UI（协议 §4），两页：`settings`（通用页里的全部设置，含记忆记录的开关和暂停）、`apps`（有单独设置的应用，点列表里的一个就在列表里展开它的设置）。窗口点完按钮会不带参数重新读页，所以展开的是哪个应用由只读的 `ime_page` 记在 `~/.luoke/ime/window-page.json`（只有 `{"apps": "<bundle id>"}`，输入法不读它）。配件清单写 `transport`、`service.pages`、`actions`（`ime_set`）。
- **只改一张写死的表**：`ime_set` 只认 `SettingsService` 里列的键，值的类型逐个核，没带 `ai.luoke/user-action`（用户在页上点了）的不改。确认第三方引擎（`approved_engines`，牵涉沙盒）、主控地址、开发模式不在表里；输入方案只能选自带的和已经确认过的。设置文件读不懂、还是第 1 版时不写。
- **只在输入法自己窗口里的**：学到的词、忘掉的词（要经正在运行的打字引擎来改）、使用统计、开发模式、打开文件夹。
- **两边同时改**：正在运行的输入法每秒看一次设置文件的修改时间，读到新的马上生效，自己的设置窗口跟着刷新；自己存盘前也先读一遍外面改过的，不拿手里旧的那份盖掉（记住各应用的中英文模式时最常存盘）。

## Considered Options

- **整个搬进主窗口、关掉自己的设置窗口**（最初的提议）：没装螺壳的人就改不了设置；麦克风也得挪成螺壳的权限，可录音的是输入法自己的进程。
- **在输入法进程里开 socket**：输入法是系统按需拉起的，没在打字时可能不在，页面就显示「没在运行」；设置本来就在文件里，短命的命令行读写文件就够。
- **单选用 `ChoicePicker`**：改了值不调工具，写成一排按钮，当前那个是主按钮（按钮里放勾的图标的话，旁边有别的按钮时窗口只画图标、不画字）。
- **「各应用」页一次展开所有应用**：一页最多 200 个组件，只放得下 5 个左右；用只读工具回的卡片重画，窗口不认（它重新读页）。
