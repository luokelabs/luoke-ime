# 系统里只注册壳这一项输入法，引擎在壳的菜单里切换

系统输入法列表里有哪几项，写死在安装包的 Info.plist（`ComponentInputModeDict`）里，新增一项要改包、重新签名，往往还要注销重登。所以壳在系统里只注册一项，引擎放进引擎目录就出现在壳的菜单里，同一时间只运行一个当前引擎，用菜单或快捷键切换——随手写的引擎不需要重装壳就能用。

## 考虑过的做法

- **每个引擎注册成系统里独立的一项**：最像原生、能用系统切换键，但每加一个引擎都要重新打包签名。
- **壳预留固定的几个系统位置（"引擎 1"到"引擎 5"）让用户绑定**：能用系统切换键，但系统里显示的名字不说人话。
