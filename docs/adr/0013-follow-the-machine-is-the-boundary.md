# 照"本机就是边界"改：记忆记录默认开，什么交给个人化组件照一张表

2026-10-19 定（顶层 ADR 0013：数据不出用户自己的设备，本机组件之间不为隐私设限）。输入法的核查清单照推荐定。

去掉的（为了少看数据而设的）：

- 记忆记录默认关 → **自带的个人化组件默认开**，第一次提示一句，全局设置里能关；设置里改存"用户关掉了谁"（`memory_off`），以前问过没开的照旧关着。
- 一段里有凭证、证件账号就整段不记，连段里的改选、删改 → **只遮那一串**（luoke_mem 的 `mask_secrets`），其余照记。
- 健康、财务这类标上类别、联想不用 → 健康、法律、宗教政治只标类别，不藏；联想用全部写过的；财务不再标（luoke-mem 定）。
- 上屏记录不放前文 → **带前文、标成第三方**（`data.context`）。
- 个人化组件只读自己写的记录 → 能读别的工具的记录和全部理解（luoke-mem 0.23 起）。
- 引擎忘掉的词只存哈希 → 存原文，设置窗口里列得出、能撤销。

保留的（安全上的）：安全输入时什么都不记、不学；用户自己设的"禁止记录""暂停"；第三方引擎不能联网、启用要确认（ADR 0012）；第三方个人化组件碰记忆要另外同意，在不能记的时候收不到转问和联想；所有引擎都在沙盒里。

## 一张表

原来"能不能交给个人化组件"散在会话（三个判断）、转问、联想、沙盒几处，是 10-14 到 10-16 一处处补出来的。现在照 `PersonalPolicy` 一张表（安全输入 × 第三方 × 用户的禁止和暂停 × 记忆记录开没开 → 写记忆、引擎学改选、转问打分、联想、开发模式的记录），会话、转问、开发模式的记录都读它，测试照表逐格写。自带的组件在禁止记录的应用里、暂停时照常打分和联想：它不存这些请求的内容，只是不写记忆。

## Considered Options

- **照旧默认关，第一次问**：顶层 ADR 0013 的理由正是这个：新用户从打字里什么都学不到，本机 AI 唯一的优势就丢了。
- **禁止记录的应用里连打分、联想也不给自带组件**：用户设"禁止记录"要的是不留下记录；打分、联想不留下东西，关了只会更难用。第三方组件不同，它可能自己存下来，所以不给。
