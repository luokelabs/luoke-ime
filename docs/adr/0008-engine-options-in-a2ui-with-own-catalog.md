# 引擎选项用 A2UI v0.9.1 格式描述，配我们自己的小组件目录

引擎在引擎说明里用 A2UI v0.9.1 的格式（扁平组件 + 数据模型 + 路径绑定）描述选项界面，组件只能来自壳自己的组件目录（文字、开关、单选、滑块、文本框、按钮、分隔线、行和列），壳用系统样式原生绘制，引擎无法控制外观。选它是因为静态和动态是同一套格式：第一版只做引擎说明里写死的静态界面，以后引擎要在运行中推送更新（如模型下载进度、"已学到的词"列表带"忘掉"按钮），可以直接走引擎的标准输入输出，格式不变。

## 考虑过的做法

- **自定极简格式（名字、类型、默认值）**：眼下最简单，但做动态时要迁移一次。
- **完整采用 A2UI 自带组件目录**：设置页会变成通用界面渲染器，离"像苹果"更远。

## 后果

- A2UI 仍在演进（v0.8→v0.9 改过消息名，v1.0 还是候选版），所以锁定 v0.9.1，不依赖任何 A2UI 库。
- 官方 SwiftUI 渲染器尚未发布（2026-10），渲染器由我们自己写，只覆盖组件目录里那几种。
