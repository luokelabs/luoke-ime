# 壳用纯 Apache-2.0，不加商业限制，名字另行保护

壳以 Apache-2.0 开源，不附加任何商业限制；另写一份名称和图标使用说明（Apache-2.0 第 6 条本就不授予商标权）：代码随便用，但不能用我们的名字和图标发布改版。鼠须管、威注音只参考行为，不抄代码。

理由：壳的价值在于有人愿意为它写引擎，任何商业限制都会让它不再算开源，劝退开发者，也进不了 Homebrew 官方仓库；壳刻意做得很薄，值得保护的东西在引擎里，引擎是独立仓库、可各自选许可证；Apache-2.0 是宽松许可，将来若要对新版本加限制，不必回头征得每个贡献者同意（已发布版本收不回）。

## 考虑过的做法

- **GPL-3.0**：可以直接抄鼠须管的代码，但限制了壳被拿去用的范围。
- **FSL（两年内禁止竞品，之后转 Apache-2.0）**：防抄做竞品，但不算开源。
- **PolyForm 非商用**：限制最强，对生态伤害也最大。

## 后果

- 小鹤引擎若打包雾凇词库（GPL-3.0-only），引擎本身须遵守 GPL；引擎是独立进程，不影响壳。
- 壳要以沙盒启动任意子进程，上不了 App Store，只做 Developer ID 签名、公证，经 GitHub Releases 分发。
