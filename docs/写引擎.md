# 写一个螺壳输入法引擎

这一页写给要写引擎的人和他的 agent。读完就能写出一个能用的引擎；字段的完整定义见[引擎协议.md](引擎协议.md)。

## 引擎是什么

一个独立程序，任何语言都行。壳把用户敲下的键攒成**输入串**，每变一次就问引擎一次："输入串是这个，前文是那个，该出哪些候选？"引擎回一份候选列表，每个候选写明自己用掉了输入串开头的几个键。退格、选词、翻页、上屏、标点、中英切换全由壳处理，引擎不用管。

对话方式：引擎从标准输入逐行读 JSON，往标准输出逐行写 JSON。

## 最小引擎

一个文件夹，两个文件（就是 [examples/minimal](../examples/minimal)）：

`engine.json`：

```json
{
  "protocol": 1,
  "name": "最小示例",
  "kind": "typing",
  "run": ["luoke-python", "engine.py"],
  "input_keys": "abcdefghijklmnopqrstuvwxyz"
}
```

`engine.py`：

```python
import json
import sys

TABLE = {"ni": ["你", "呢", "泥"], "hao": ["好", "号"], "nihao": ["你好"], "wo": ["我", "握"], "women": ["我们"]}

for line in sys.stdin:
    msg = json.loads(line)
    if msg.get("type") != "query":  # 不认识的消息一律忽略
        continue
    keys = msg["input"]
    candidates = [{"text": text, "consume": n}  # 从最长的前缀开始查，整句优先
                  for n in range(len(keys), 0, -1) for text in TABLE.get(keys[:n], [])]
    print(json.dumps({"type": "answer", "id": msg["id"], "candidates": candidates}, ensure_ascii=False), flush=True)
```

`luoke-python` 是螺壳主控带的 Python（3.12，只有标准库），装了螺壳的机器上一定有；没装主控的开发机上，壳用 PATH 里的 `python3`。

不装输入法也能直接试：

```bash
echo '{"type":"query","id":1,"input":"nihaowo"}' | python3 engine.py
```

输出 `你好`（用掉 5 个键）、`你`（用掉 2 个键）……用户选了"你好"，壳会拿剩下的 `wo` 再问一次。

## 必须遵守的规则

1. **标准输出只写协议消息，每条后面立刻 flush。** 日志写标准错误。
2. **忽略不认识的消息类型和字段。** 壳会发 `hello`、反馈等消息，你不处理就跳过。
3. **答复带上询问的 `id`。** 旧询问的答复会被壳丢掉，所以不必担心顺序，但别漏写 `id`。
4. **`consume` 在 1 到输入串长度之间。** 首选最好用掉整个输入串。
5. **不要写引擎文件夹。** 它是只读的。要存东西（学到的词、缓存），写到环境变量 `LUOKE_IME_DATA` 指向的目录。
6. **不能联网；要麦克风先在 `permissions` 里声明。** 你写的引擎是第三方引擎：不能联网、不能用 GPU、只能写自己的数据目录（`LUOKE_IME_DATA`），`permissions` 里写了 `network`、`gpu`、`write` 就不启用。要用模型就经壳转问螺壳主控（见下面的"要用模型"）。用户第一次启用它时会看到确认框，列出它要的权限。没声明的操作会被沙盒拦下，`luoke-ime check` 和 `try` 会告诉你拦了什么。沙盒里用不了 `ps`、`ping` 这类 setuid 程序，也打不开网址、读不了剪贴板，读不了 `~/.ssh`、钥匙串、浏览器数据这类。

## 常见的进阶需求

**慢的计算（比如模型重排）**：先用快的办法答复，带上 `"more": true`，算完再用同一个 `id` 补发一份完整列表（不带 `more`）。壳会挑合适的时机替换，不会在用户手指底下换词。处理补发期间若读到更新的询问，可以直接放弃旧的计算。

```json
{"type": "answer", "id": 9, "candidates": [{"text": "星云", "consume": 4}], "more": true}
{"type": "answer", "id": 9, "candidates": [{"text": "行云", "consume": 4}, {"text": "星云", "consume": 4}]}
```

**模型加载慢**：启动后立刻开始读标准输入，模型在后台加载；加载完成前只用词库答复。

**要参考前文**：在 `engine.json` 里写 `"context": 200`，询问里就会带上光标前最多 200 个字。

**从用户的选择和修改里学习**：写 `"feedback": true`，就会收到 `committed`（上屏了什么、每段选的第几个）、`deleted`（上屏后紧接着删了几个字）、`revised`（上屏的字后来在输入框里被改成了什么）、`forget`（用户要求忘掉某个候选）。怎么理解这些事件、学不学，全由你决定。学了东西存在自己的数据目录里的，再写 `"forget_all": true`：菜单和设置「记忆」页里就有"清掉学到的词"，用户确认后你收到 `forget_all`，把学到的东西真的从文件里删掉。

**给候选加说明**：候选里加 `"note": "bù"`，候选窗里会以灰色小字显示。先快后好时，补发里被慢的那一路（比如模型）改过的候选，约定在注释里写 `✦`：壳等补发时也在候选条末尾显示呼吸的 ✦，用户看到的是同一个意思。

**让用户调选项**：在 `engine.json` 里用 `options` 描述界面（开关、单选、滑块等，A2UI 格式），壳负责画设置页，值经 `hello` 交给你，改了会重启你。

**按快捷键触发（语音、图片识字）**：`"kind": "hotkey"`，声明 `hotkey`。收到 `start` 后不断发 `show` 更新光标处的文字，最后发 `commit` 上屏；收到 `cancel` 就停。

**要用模型**：不要自己加载模型，经壳转问螺壳主控：在 `engine.json` 里写 `"asks": ["hub"]`，发 `{"type": "ask", "id": 1, "to": "hub", "method": "score", "params": {"task": "luoke-ime.rerank", "context": "…", "candidates": ["…"]}}` 给候选打分，或者 `"method": "continue"`（`"task": "luoke-ime.predict"`）让模型接着写。主控只算概率，怎么截、怎么挑、什么算有把握你自己定。主控没在运行、模型在加载时答错误，引擎照常出候选。见[引擎协议](引擎协议.md#转问)。

**要用户的个人化（常用说法、打分、联想）**：不要自己存用户的历史，问个人化组件。在 `engine.json` 里写 `"asks": ["personal"]`，发 `{"type": "ask", "id": 1, "to": "personal", "method": "score", "params": {…}}`，等同一个 `id` 的 `reply`（`result` 或 `error`）。等多久你自己定，不等了就把晚到的丢掉。声明了这一条，引擎就不能联网出去（`network` 只能是 `none`，或 `local` 加 `local_ports`）。见[引擎协议](引擎协议.md#转问)。

**写个人化组件**：`"kind": "personal"`，不联网。会收到所有引擎的 `committed`（带 `kind`、`source`、`app`）、`deleted`、`revised`、`forget` 和转来的 `ask`（带 `from`），每个 `ask` 都要答一条 `reply`。参考 `engines/personal`，字段见[引擎协议](引擎协议.md#个人化组件)。

## 测试

- `luoke-ime check <引擎文件夹>`：自动检查协议格式、答复速度、补发、反馈、崩溃、退出等，输出一份可直接读的报告，有问题时退出码为 1。改完代码先跑它。
- `luoke-ime try <引擎文件夹> --keys '<按键脚本>'`：不需要终端，按脚本打字，逐键打印光标处、候选和输入框，最适合 agent 自己验证行为。普通字符照打，特殊键写在花括号里，例如：

  ```bash
  luoke-ime try . --context "今天" --keys 'nihaowo1{space},women{right}{space}'
  ```

  可用的特殊键：`{space}` `{enter}` `{bs}` `{esc}` `{left}` `{right}` `{up}` `{down}` `{pgup}` `{pgdn}` `{shift}`（切中英）`{forget}`（Shift+⌫）`{hotkey}`（快捷键引擎，配合 `--hotkey <文件夹>`）`{wait:200}`（等 200 毫秒）。
  加 `--personal <文件夹>` 同时装上个人化组件：上屏转给它（最后列出转给它的每条消息），打字引擎可以转问它；记忆用临时的一份。
- `luoke-ime try <引擎文件夹>`：交互模式，在终端里像真的输入法一样打字试，给人用。
- 引擎装在 `~/.luoke/ime/engines/<标识>/` 时，第一次在菜单里选它会弹确认框；确认后改动文件，壳会自动重启它，下一个键就是新版本（只改代码不用重新确认，改了权限要）。和 LuokeIME.app 里自带的同名的，确认后才代替自带的那份。
- 用 Python 写、只用标准库的话，`run` 写 `["luoke-python", "engine.py"]`：用户的机器上不一定有能用的 `python3`（干净的 Mac 上 `/usr/bin/python3` 会弹窗要装开发工具），螺壳主控带的那份一定在。
