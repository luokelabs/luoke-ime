# 全拼引擎

螺壳输入法的打字引擎，和[小鹤双拼](../xiaohe)共用一份代码（`../xiaohe/*.swift`，以 `--scheme quanpin` 运行），候选来源、模型重排、记忆、emoji 和英文单词都一样，见那边的说明。模型在[个人化组件](../personal)里，经壳转问它打分。

不同的只有按键：原始字母直接交给苹果的转换引擎，音节怎么切、每个候选用掉几个键都按它给的拼音段和音节长度算。所以：

- 连着打就行，歧义交给苹果和模型：fangan → 方案 / 反感，xian → 先 / 西安。
- 简拼可用：nh → 你好。
- 打错字母不纠：苹果会把拼不成音节的字母当成简拼（zhognguo 切成 zho g n guo，首选"中国难过"），不会当成打反了的 zhong guo。原来这里写的"zhognguo → 中国"不对（luokelabs/luoke-ime#3，用命令行版核过，RIME 就绪前后一样）。
- ü 用 v：lvse → 绿色。
- 光标处显示苹果切分后的拼音（ni hao），能看出有歧义的串是怎么切的；拼不成拼音的（比如 hello）原样显示。
- 增量复用要往后看 12 个键（约 4 个音节）才沿用。

博客语料 600 条（按键换成全拼）：苹果首选 78.8%，模型重排后 89.8%，和小鹤双拼几乎逐条相同（只有 1 条不同）。逐键打时（每个键都等引擎答完）沿用已定的词的那份答复 89.5%，停下后从头再选的 89.8%；最后一个键到答复 p90 98 ms（M5 Max）。

```bash
./build.sh                       # 编译（用 ../xiaohe 的代码）、拷词库、自检
luoke-ime check .
../xiaohe/bench.py 语料.tsv --engine .    # 语料的按键一列要换成全拼
```

随 LuokeIME.app 发布（和小鹤共用包里的 `lib/` 和词库）；在输入法菜单里选「全拼」。开发时把这个文件夹复制到 `~/.luoke/ime/engines/quanpin`，会盖过包里的那份（用完挪走）。
